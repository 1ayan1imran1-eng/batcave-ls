## Vault

Click any file card to open its workspace. Each type is a real editor:

- **Roadmap** — START and END stay on the board, connected by red string. Add steps between them, drag, re-string, mark status.
- **Blueprint** — draw on a grid. Undo / clear / colors / weight.
- **Dossier** — long-form sections.
- **Evidence** — pinboard with red string.
- **Mission** — planned / active / done.

Destroy a file from the card (**Destroy**) or from inside the file (**Destroy file**).

Files live in this browser. Optional encrypted remote backup is on the System page.
